## 課程評量與出缺席規定
* **平時成績 (30%)**：評估標準為「人到、耳到、眼到、手到、心到」。上課需簽到，第一節開始20分鐘後視為遲到，未簽到則為缺席，請假需事先告知。
* **期中作業 (30%)**：以專利文件閱讀心得為主。
* **期末報告 (40%)**：分為書面報告 (70%) 與口頭報告 (30%)。書面評分著重於創意、技術內容完整度及邏輯性、符合專利要件程度與可用性。口頭評分著重於技術內容完整、表達清晰充分，以及對專利知識及問題的回應。

## 期中作業具體要求
* **指定題目**：針對第111143811號專利「多通路上架商品之自動配量系統及其配量推薦方法」進行分析。
* **分析架構**：
  * **本案欲解決的問題**：需包含先前技術概要、先前技術缺失，以及本案欲解決的問題（目的）。
  * **解決問題的技術手段**：拆解為核心技術手段（包含特別技術特徵與一般技術特徵）及附加技術特徵。
  * **達成之功效**：列出有別於先前技術之功效，以及有利或無法預期之功效。
  * **個人心得**：分析本案技術是否無法解決問題、技術上可改良之處，或指出其技術內容揭露未明確且充分導致無法據以實現的部分。

## 期末報告具體要求
* **主題設定**：題目自訂，領域以資訊、通訊或日用品為主。
* **文件撰寫要項**：必須包含發明名稱、發明想法、最接近之先前技術（經檢索或普遍經驗得知）、先前技術缺失、本發明技術手段、解決問題、發明目的、實施方式及圖式等項目。
* **請求項規定**：申請專利範圍至少需包含1項獨立項與1項附屬項。
